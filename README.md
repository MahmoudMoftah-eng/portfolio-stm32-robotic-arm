# STM32-Based Robotic Arm — Cascaded PID Position Control

## Overview
Developed embedded C firmware for an STM32F446RE robotic arm in a three-person team.

## My contribution
- Implemented timer-driven cascaded PID control.
- Built a 100 Hz position loop and a 1 kHz velocity loop.
- Designed an H-bridge motor driver interface.
- Tuned the controller through MATLAB/Simulink simulations and hardware testing.

## Technologies
Embedded C · STM32F446RE · PID Control · MATLAB/Simulink · H-Bridge Motor Driver

## Availability
This repository is a public project case study. It does not include team source code or hardware design files.
